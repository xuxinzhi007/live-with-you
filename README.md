# 桌面宠物 · 雯宝

网页版桌面宠物。状态图会自动切到对应动作。

## 怎么运行

用浏览器打开 `index.html`，或重新部署到 Netlify。

## 状态图

| 动作 | 使用图片 |
|---|---|
| 待机 / 散步 / 挥手 | `assets/idle.webp` |
| 坐下（休息） | `assets/rest.webp` |
| 睡觉 | `assets/sleep.webp` |
| 跳跃 / 开心 | `assets/jump.webp` |

中文原图会留在本地，部署只用上面这些英文小图，手机上更稳。

## 操作

- 点地板：雯宝走过去
- 点头：摸摸，出爱心
- 点身体：挥手
- 连点三下：开心跳
- 拖起来再放下：落地；从很高处摔下会晕一下
- 丢玩具：她会跑去捡
- 方向键走动，空格跳，F 丢球
