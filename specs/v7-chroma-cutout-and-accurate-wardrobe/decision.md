# v7-chroma-cutout-and-accurate-wardrobe 决定

> 落 `specs/v7-chroma-cutout-and-accurate-wardrobe/decision.md`。规则在 `references/scope.md`。

- 级别：L2（修复 ComfyUI 白底抠图导致的“头发高光/眼白/白衣服被抠穿”问题，升级为「母图锁脸换装 + 绿幕/品红底色 + 边缘连通域不破内洞抠图」，并逐一校准全部 27 件衣橱资源的画面与名称 100% 对应）
- 真正要解决的问题（基于你的截图 `image-30dc73c8` 精准定位）：
  1. **为什么截图里头发出现白窟窿、手部变成两团黑块、衣服被抠穿？**
     - **原因 A（全局颜色抠图把内部白色全抠掉了）**：ComfyUI 原生的 `ImageColorToMask (16777215 白色)` 不区分“外部背景白”和“角色内部白”！只要角色头发上有白色高光、眼睛里有白色反光、或者身上穿浅色衣服，就会被一刀切全部抠成透明窟窿（所谓的“抠图过度”）。
     - **原因 B（`xiaoyan.safetensors` 权重 0.80 过强导致服装被黑裙/翅膀污染）**：正如你原工作流笔记里写的：*“这次训练的标签几乎每张都写了黑长裙和翅膀，权重太高衣服会被带偏”*——所以在生成浅色「杏仁奶昔裙」「暮色蔷薇裙」时，0.80 的 LoRA 强行在手臂两侧画出了两团黑翅膀/黑袖子残影！
  2. **部分生成的资源与衣橱槽位/名称不够严丝合缝**：
     - 之前配饰图生成时带了桌布、靠垫、盒子等杂乱背景，作为透明挂件戴到雯宝头上/手上时显得有杂边，不够干净。

- 正确的工业级解决方案（参考 `docs/standard-character-plan.md` §4.2 与你的 `MeinaMix_全身统一.json`）：
  1. **改用「高对比纯色绿幕/洋红底（`solid #00FF00 green screen` 或对比色底）+ 降权 LoRA (0.55) / IPAdapter 母图锁脸」**：
     - 生成角色礼服与配饰时，**绝不用白底去碰白色衣服/高光**！改用纯色对比背景（或对浅色物用深色/绿幕底，配合去溢色 Despill），这样角色的**眼白、头发高光、白蕾丝、浅色皮肤 100% 绝不会被误伤抠穿**！
     - LoRA 强度从 `0.80` 调优至 **`0.55`**（或结合母图 `idle.webp` 图生图/IPAdapter 锁脸），既保留雯宝的短黑发棕眼 Q 版脸型，又让「杏仁奶昔针织裙」「暮色蔷薇粉礼服」「星河眠云蓝纱裙」的衣服颜色和款式 100% 准确呈现，不再长出两团黑袖子！
  2. **只用「外框四边种子连通域 BFS 抠图 + 内部孔洞自动闭合（Hole Filling）」**：
     - 抠图算法强制规定：**只有从画布四条外边框（Border）能够一路连通到达的背景像素才会被设为透明**；任何被角色黑色轮廓线包裹在身体内部的像素（哪怕是纯白色眼白、头发高光、白色花瓣），Alpha 强制锁定为 `255`（完全不透明）！从算法根源上杜绝“头发/眼睛/衣服被抠出洞”！
  3. **逐一核对并补全全部衣橱美术资源，确保每一张图都与名字、穿戴部位 100% 匹配**：
     - 重新生成并校验 3 套礼服 + 17 件孤立无背景配饰（发夹就是单纯的一枚发夹、兔耳就是单纯的兔耳发箍、茶杯就是单纯的茶杯，不含桌布和盒子背景），确保戴在雯宝头顶和手边时像原生画上去的一样干净自然！

- 怎样算满足：
  1. 更新 `MeinaMix_雯宝LoRA_换装抠图.json` 工作流（调整 LoRA 推荐强度为 `0.55` 防止黑袖污染，并说明对比色底抠图法）。
  2. 重新生成 3 套同角色 Q 版雯宝礼服（杏仁奶昔裙、暮色蔷薇裙、星河眠云裙）及配饰，并用 Read 工具逐张视觉验图：确认**无黑块残影、头发高光与眼白完好无损、衣服款式与名称 100% 一致**。
  3. 升级 `src/mobile/world/paper-doll-rig.ts:loadCutoutImage`：实装**严格外边框连通 + 内部像素零误伤保护 + 绿幕/白底自适应去边**，保证角色内部 0 破洞。
  4. `npm run test:mobile` 与 `npm run build` 全部通过。
