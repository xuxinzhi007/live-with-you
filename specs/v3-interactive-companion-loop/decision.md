# v3-interactive-companion-loop 决定

> 落 `specs/v3-interactive-companion-loop/decision.md`。规则在 `references/scope.md`。

- 级别：L3（彻底推倒旧 V0/V1/V2 横版跑图框架，清理历史僵尸代码，重构为全新的 V3 竖屏交互式伴侣养成 + 奇遇扭蛋 + 全图鉴收集架构）
- 真正要解决的问题：
  1. **旧框架（横版卷轴 + 点地寻路跑腿 + 找门切场景 + 罚站长冷却）从根上设计错误**：窄竖屏里拖着相机点地面跑腿毫无游戏性，把陪伴对象做成了跑腿工具人。
  2. **三代历史包袱混杂（`src/game/`、`src/layouts/MobileLayout.tsx`、`src/mobile/multiplayer/`、`src/mobile/engine/pixi-stage.ts` 等）**：仓库里 60% 是废弃的旧代码，且 V2 反而把最核心的养成等级、图鉴收集、聊天互动、奇遇事件全丢了。

- 怎样算满足（全新 V3 架构验收标准）：
  1. **物理清理全部 V0 / V1 僵尸代码与旧横版跑腿逻辑**：
     - 删除 `src/App.tsx`、`src/Studio.tsx`、`src/CharacterDetail.tsx`、`src/game/**`、`src/layouts/**`、`src/mobile/SceneStage.tsx`、`src/mobile/CharacterCreate.tsx`、`src/mobile/FindPartnerSheet.tsx`、`src/mobile/multiplayer/**`、`src/mobile/data/**`、`src/mobile/engine/{GameEngine,game-rules,pixi-stage,stage-motion,useStagePresence,world,index}.ts`、`src/mobile/mobile-layout.css`。
     - `src/main.tsx` 唯一入口直接挂载全新的 V3 应用。
  2. **全新 V3 核心架构（一屏聚焦交互舞台 + 雯宝自主生命力 AI + 零跑腿秒响应）**：
     - **单屏聚焦舞台**：不再做横版长走廊拖相机，也不再点地面走路；每个场景（`🏠 小屋` / `🌿 庭院` / `⛲ 街区`）都是一屏聚焦的精致交互舞台，玩家通过场景切换栏**一键瞬切场景**。
     - **雯宝居中放大 + 自主微 AI + 头顶心愿气泡**：雯宝在画面核心位置（支持呼吸、眨眼、开心跳跃、坐下读书、躺下小憩、自主轻移），每隔一会儿头顶自动浮现**「此刻心愿气泡」**（如 `🍪 想吃小点心`、`🌼 想去照料花圃`、`🎵 想听八音盒`、`✨ 想去喷泉许愿`）；顺应心愿互动触发 **双倍亲密暴击 + 专属台词**。
     - **直接点角色 / 点物件 / 点底部行动卡立即结算 + 屏幕动态飘字（Floating Juice）**：每次互动零跑腿等待，直接切换姿态演出并弹出 `+亲密 EXP`、`+零钱`、`+心情`、`✨ Lv.UP!` 动态飘字。
  3. **深度养成、自选花园经营、街区奇遇二选一 & 喷泉扭蛋、18 项全图鉴收集（N / R / SR）**：
     - **亲密等级体系（`Lv.1 ~ Lv.10`）**：顶栏实时显示等级徽章、称号、经验进度条（`bond` 驱动），升级奖励零钱与解锁新互动。
     - **自选种植 + 花束变现/插花闭环**：庭院 3 块花圃支持**玩家自己选择种哪种花（雏菊 / 小玫瑰 / 向日葵 / 培育稀有花）**，支持一键浇水催熟与收花；收到的花束可在小屋**插进桌面花瓶展示**，或在街区**完成花摊委托换取丰厚零钱**。
     - **街区喷泉「许愿扭蛋池」+「街区奇遇事件（二选一）」**：消耗零钱在喷泉许愿可抽取 **18 项全图鉴藏品（分 `N / R / SR` 稀有度：🌸 4 种花卉、🎁 8 件珍藏摆件实物上柜、📸 6 张奇遇记忆卡）**，并可触发带分支选项的奇遇小故事。
     - **内置「和雯宝聊天」抽屉**：直接整合同源 `companion-scene`（支持快捷话题一键发话 + 自由输入聊天 + 离线高情商本地回退）。
  4. 全套全新 V3 单测（`npm run test:mobile`）与生产构建（`npm run build`）100% 通过。

- 现有能力（只保留真正有价值的资产与同源服务）：
  - 保留 `public/assets/characters/{original,maid}/` 与 `public/assets/scenes/` 全部贴图资产。
  - 保留 `netlify/functions/companion-scene.mjs` 与 `vite.config.ts` 的 Ollama 同源服务。
  - 保留 `wenbebi-mobile-game-v2` 本地存档 key 并平滑升级支持 V3 等级、图鉴、桌面插花与心愿系统。

- 最小充分方案：
  1. 已拍板：执行这次彻底大换血（物理清理 V0/V1 全部旧文件 + 废除横版跑图框架 + 上线全新 V3 交互式陪伴养成/自选种花/许愿扭蛋/18项全图鉴/实时聊天系统）。

- 为什么更小的做法不够：
  - 在横版卷轴跑图框架上修修补补无法改变“走路模拟器”的底子，唯有彻底换成以角色互动、数值成长、盲盒奇遇、图鉴收集为核心的 V3 舞台架构，才能真正做成好玩的游戏。

- 相关的债：
  - **A 现在偿还**：一次性铲除 V0、V1 和 V2 横版跑腿的全部历史僵尸代码（清理约 35 个废弃文件）。

- 这次不做：
  - 不做需要后端 WebSocket 中继的假双人联机。

- 风险：旧单测中针对 V1 双人房间码/旧家具坐标的测试将随 V1 代码一并移除，替换为覆盖 V3 等级成长、自选种花、花束委托、许愿扭蛋保底、18 项图鉴进度、心愿暴击与存档兼容的完整单测套件。
