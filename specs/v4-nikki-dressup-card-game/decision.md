# v4-nikki-dressup-card-game 决定

> 落 `specs/v4-nikki-dressup-card-game/decision.md`。规则在 `references/scope.md`。

- 级别：L3（彻底移除粗糙的 Pixi 2D 家具房间舞台，转型为《奇迹暖暖》式「看板娘立绘衣橱 + 5 槽位换装搭配 + 主题关卡 S/SS/SSS 维度打分 + 星愿幻阁抽卡」卡牌换装游戏）
- 真正要解决的问题：
  1. **Pixi 2D 拼贴房间与家具质感粗糙、缺乏真正的单局游戏过程**：把高颜值角色放进简陋矢量家具房间里点来点去，没有搭配策略、没有闯关评分过程、也没有立绘卡牌的精致包装感。
  2. **需要真正的《奇迹暖暖》式核心循环**：玩家需要的是「看关卡主题要求 → 在衣橱搭配服饰/头饰/手持物/香氛/心境羁绊卡 → 五维属性（甜美/优雅/清纯/温暖/清凉）逐项跳分评定 `C/B/A/S/SS/SSS` → 赢取星钻与金币 → 去幻之阁抽 SSR/SR 新部件与升星突破」。

- 怎样算满足（V4 奇迹暖暖式卡牌换装架构验收标准）：
  1. **干掉粗糙的 Pixi 2D 家具房间，换上「精致立绘卡牌主舞台 + 动态粒子光效 + 视觉挂件叠加」**：
     - 舞台中央是带**鎏金画框、星级角标、柔光呼吸动画、动态飘落光斑**的雯宝高清立绘（支持呼吸帧切换、开心/害羞互动动态、以及在立绘周围/身上实时展示当前佩戴的**头饰徽章、手持物、香氛光环与心境羁绊卡**）。
     - 清理不再使用的 Pixi 2D 房间渲染器 `WorldView.tsx`（释放约 300KB 的 Pixi WebGL 打包体积），让页面加载闪电般快、视觉 100% 统一为精致的暖暖风 UI。
  2. **5 大穿搭与卡牌槽位 + 五维属性体系（甜美 / 优雅 / 清纯 / 温暖 / 清凉）**：
     - 新增 `src/mobile/world/nikki-wardrobe.ts`：
       - **5 大槽位**：`dress`（主装扮，切换白色初雪裙 / 小鲸鱼女仆装 / 晨曦微光礼服 / 星夜睡裙等立绘与光效滤镜）、`hairAcc`（头饰，6 件）、`handheld`（手持物，6 件）、`aura`（香氛光环，5 件）、`memoryCard`（心境羁绊卡，6 张）。共计 **27 张精美服饰与心境卡（分 `R 3★` / `SR 4★` / `SSR 5★`）**。
       - **五维风格分**：每件单品拥有主副风格标签（`甜美`、`优雅`、`清纯`、`温暖`、`清凉`）与基础魅力分；抽到重复单品自动 **升星突破（`★1 → ★5`，每升一星全属性 +15%）**！
  3. **6 大主题出行闯关章节（Styling Stages）+ 华丽五维跳分结算（`C / B / A / S / SS / SSS`）**：
     - 每关有明确的**剧情引言、主题要求标签（如 Stage 1「街角初遇下午茶」主考【甜美 + 清纯】）、目标 S 级分数线与首通星钻大奖**。
     - 点击「✨ 开始搭配评比」后，弹出华丽的**五维得分结算演出（显示甜美分、优雅分、清纯分、温暖分、清凉分、羁绊卡技能加成、总分与 `SSS / SS / S / A / B` 大印章）**，发放金币与星钻奖励。
     - 内置「💡 一键推荐最优搭配」与「手动自由换装」双模式，兼顾策略感与爽快感。
  4. **「✨ 星愿幻阁」单抽 / 五连抽卡池 + 全衣橱图鉴 & 雯宝伴侣聊天**：
     - 支持消耗金币或星钻进行**单次许愿 / 五连许愿（五连必出 SR 或 SSR！）**，新卡解锁衣橱，重复卡自动升星提高闯关分数。
     - 完整保留与雯宝的面对面聊天抽屉（同源 Ollama + 本地高情商回退）。
  5. `npm run test:mobile` 与 `npm run build` 100% 通过。

- 现有能力：
  - `public/assets/characters/{original,maid}/` 高清立绘帧与头像直接作为主服装的核心立绘源。
  - `netlify/functions/companion-scene.mjs` 继续提供雯宝对话与评语能力。

- 最小充分方案：
  1. 已拍板：按上述《奇迹暖暖》式架构（1.干掉 Pixi 2D 家具房间，换上鎏金立绘卡牌舞台+粒子光效 2.实装 5 大槽位 27 件 R/SR/SSR 服饰与心境卡+重复升星 3.实装 6 大主题搭配闯关与五维 S/SS/SSS 跳分结算 4.星愿幻阁单抽/五连抽）执行本次重构。

- 为什么更小的做法不够：
  - 如果还留着那个粗糙的 2D 家具房间，不管怎么改按钮都摆脱不了廉价感；只有彻底换成《奇迹暖暖》式的立绘衣橱舞台 + 5 槽位属性搭配 + 主题闯关打分 + 幻阁抽卡升星，才有真正的游戏过程和收集动力。

- 相关的债：
  - **A 现在偿还**：移除不再需要的 `WorldView.tsx` Pixi 2D 房间渲染器，消除 WebGL 重型依赖与粗糙家具贴图。

- 这次不做：
  - 不破坏本地存档恢复能力（自动从旧档继承金币、亲密度与已解锁记录）。

- 风险：无外部服务风险，所有搭配打分、关卡进度、幻阁保底、卡牌升星均为纯函数，可 100% 单测验证。
