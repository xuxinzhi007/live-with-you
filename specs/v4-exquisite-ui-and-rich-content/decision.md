# v4-exquisite-ui-and-rich-content 决定

> 落 `specs/v4-exquisite-ui-and-rich-content/decision.md`。规则在 `references/scope.md`。

- 级别：L1（全面精修《奇迹暖暖》式 UI 排版与视觉质感，消除模拟器竖排折行与方框乱码，并扩充套装图鉴、单品详情情报卡、当前关卡目标预览等丰富内容信息）
- 真正要解决的问题（基于真机模拟器截图 `image-938410fa` 逐像素诊断）：
  1. **5 处明显的排版瑕疵与乱码**：
     - **乱码方框 `▯`**：第一张衣服卡「初雪白茶连衣裙」的图标用了 `🤍`（Unicode 12），在模拟器里又变成了刺眼的方框 `▯`；`🫧`、`🧁`、`🧢`、`🫖` 等高版本 Emoji 也存在同样隐患。
     - **文字被挤成难看的竖排折行**：右上角「`魅力`」「`衣橱`」被挤成上下两行竖字；分类 Tab 的「`羁绊卡`」被挤成「`羁绊` / `卡`」两行。
     - **「穿戴中」角标直接盖住了属性标签**：卡片右下角的「穿戴中」把「甜美」两个字挡了一半。
     - **「暖白陶土茶杯」左上角的叶子图标重叠穿模**：`.nk-aura-halo` 的绝对定位偏到了右侧挂件卡上，压住了茶杯卡片的左边缘。
  2. **舞台背景太素、缺少《奇迹暖暖》式的精致内容信息层**：
     - 舞台背景只是纯粉白渐变，缺少精致的**室内/庭院画卷远景底图 + 拱门画框装饰 + 当前套装收集横幅**。
     - 衣橱卡片只有冷冰冰的图标和名字，**没有「单品详情与故事情报栏（显示单品五维具体数值、套装归属、背景故事、升星按钮）」**，也没有**「当前闯关目标快速预览条」**，导致界面显得空洞、信息量不足。

- 怎样算满足（精致化与内容扩充验收标准）：
  1. **彻底清零所有高版本不兼容 Emoji（`🤍`、`🧁`、`🫧`、`🧢`），并定制精致矢量图标/缩略图**：
     - `dress`（主装扮）卡片直接展示**微缩版礼服立绘预览图（带专属色调与鎏金底纹）**，不再用单调的 Emoji 充数！
     - 其余配饰全部限定使用 Android 100% 兼容的经典符号与内联 SVG。
  2. **修复全部文字折行、重叠与穿模**：
     - 顶栏右侧胶囊改为 `white-space: nowrap` 单行横向排布（`💎 5340 魅力`、`👗 5/32 收集`）。
     - 5 个槽位 Tab 统一用 `white-space: nowrap`（`👗 装扮`、`🎀 头饰`、`👜 手持`、`✨ 香氛`、`🃏 羁绊`），绝不折行。
     - 「穿戴中」角标移至卡片右上角或底部独立状态条，绝不遮挡「清纯 / 甜美」属性标签。
     - 移除会飞到右侧挂件卡上的 `.nk-aura-halo` 错位元素，改为舞台内精致的顶栏套装铭牌。
  3. **舞台与信息密度全面升级（《奇迹暖暖》级精致感）**：
     - **舞台画卷底图 + 拱门金线画框**：复用 `public/assets/scenes/{home,garden,street}.webp` 作为柔和虚化的画卷底图，叠加上欧式鎏金拱门画框与柔光暗角，让雯宝立绘真正置身于精致画卷中。
     - **舞台顶部新增「套装与关卡情报条」**：实时显示当前穿戴的【套装名称 / 羁绊技能】+ 当前挑战关卡（如 `第1话·白茶会 | 距离 S 级还差/已超越 xx 分`）+ 一键「去闯关」快捷入口。
     - **衣橱新增「选中单品详情情报卡（Inspector Bar）」**：点击任意服饰/卡牌时，在衣橱上方展开精致的**单品情报卡**：显示该单品的**完整五维数值条、所属套装、浪漫背景故事描述、当前星级加成（`★1 +0% → ★2 +15%`）以及一键用礼券「✨ 升星强化」按钮**！
     - **扩充服饰与剧情内容**：衣橱扩充至 **30 件单品 + 4 大主题典藏套装（【初雪白茶】【深海小鲸鱼】【暮色蔷薇】【星河眠云】）**，集齐套装可激活额外魅力加成并领取套装大奖。
  4. `npm run test:mobile` 与 `npm run build` 100% 通过。

- 最小充分方案：
  1. 已拍板：按上述方案（1.修复 `▯` 方框、竖排折行、标签遮挡与图标穿模 2.舞台加入画卷远景底图+鎏金拱门画框+关卡目标情报条 3.衣橱加入单品详情五维情报卡+一键升星强化+4大主题套装图鉴 4.闯关过程升级为《奇迹暖暖》式多回合技能对决 PK + 套装工坊制作）执行本次精修与深度游戏化升级。
