# v4-breathing-space-layout 决定

> 落 `specs/v4-breathing-space-layout/decision.md`。规则在 `references/scope.md`。

- 级别：L1（重构《奇迹暖暖》主界面的空间呼吸感与抽屉交互架构，消除卡片截断与密集堆叠）
- 真正要解决的问题（基于真机模拟器截图 `image-635cc47d` 实测诊断）：
  1. **纵向塞了 7 层元素，导致最底下的衣服卡片文字被拦腰截断**：
     - 截图里从上到下硬塞了：① 顶栏 → ② 舞台关卡条 → ③ 立绘+左右 4 个大白框 → ④ 台词条 → ⑤ 五维数字条 → ⑥ 5 个分类 Tab → ⑦ 占了 85px 高的详情框 → ⑧ 衣服网格（**结果第一排衣服卡的字「午后阳光茶会」直接被底边裁掉了一半！**）。
  2. **立绘舞台被左右 4 个大白框挤得像“上夹板”**：
     - `.nk-float-slot` 宽 72px、带三行字，左右两列占掉了舞台 45% 的宽度，把雯宝挤在中间一条窄缝里，完全没有《奇迹暖暖》那种通透、唯美的全身立绘呼吸感。
  3. **详情框（`.nk-inspector`）常驻在网格上方，吃掉了宝贵的衣橱滚动空间**：
     - 衣橱面板一共只有 ~240px 高，分类 Tab + 常驻详情框就吃掉了 120px，留给衣服卡片的高度连一排都放不下。

- 《奇迹暖暖 / 闪耀暖暖》真正的空间与交互设计法则：
  1. **立绘舞台占 62% 屏幕高度，左右配饰化为「36px 精致半透明小圆徽章」**：
     - 拿掉舞台里那 4 个笨重的大白框、拿掉舞台底部的长台词条和 5 个花花绿绿的五维胶囊！
     - 穿戴中的 4 件配饰做成贴在舞台边缘的**小巧圆形晶钻气泡（仅 38×38px，只显示图标+右上角小星级，点击直接切到该分类）**，把 80% 的画卷空间完全留给雯宝和身后的唯美场景！
  2. **衣橱采用「底部可收放滑出抽屉 + 横向丝滑卡片流（Horizontal Carousel）」**：
     - 不再在下半屏用三列网格硬塞两排！改为《奇迹暖暖》经典的**底部横向滑动衣架（单排高颜值完整卡片，绝不截断任何一行字！）**。
     - **详情与升星按需浮出**：移除占地方的常驻大详情框，改为在衣橱抽屉顶部用**极简一行「当前选中：午后阳光茶会 ★1 (甜美+260) · [⭐升星]」**呈现，把空间全还给衣服卡片和立绘舞台。

- 怎样算满足：
  1. **零截断**：衣橱卡片（图标、名称、属性标签、星级）100% 完整显示，绝不出现截图中文字被切半的情况。
  2. **舞台留白与呼吸感翻倍**：舞台占比提升至 ~58%–62%，左右挂件缩小为 38px 精致晶钻圆钮，移除舞台内冗余的台词长条与五维色块条，雯宝全身与画卷背景通透舒展。
  3. **支持一键「👁️ 欣赏模式（隐藏衣橱抽屉）」**：舞台角落提供「收起/展开衣橱」轻按钮，收起时全屏欣赏雯宝穿搭与画卷。
  4. `npm run test:mobile` 与 `npm run build` 100% 通过。

- 最小充分方案：
  1. 已拍板：按上述「大立绘留白舞台（38px 晶钻配饰圆钮）+ 移除占高常驻详情框（改为单行轻巧升星条）+ 横向丝滑完整衣橱卡片流（彻底解决卡片文字截断）+ 可收起欣赏模式」优化空间与交互。

- 风险：纯 UI 空间布局与交互手势升级，零数据风险。
