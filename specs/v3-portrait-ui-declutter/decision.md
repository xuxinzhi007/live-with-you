# v3-portrait-ui-declutter 决定

> 落 `specs/v3-portrait-ui-declutter/decision.md`。规则在 `references/scope.md` 与 `docs/mobile-portrait-layout-research.md`。

- 级别：L1（重构 `WorldApp.tsx` 与 `world.css` 的竖屏 HUD 布局，消除遮挡与乱码框，严格对齐成熟竖屏养成游戏的黄金分区）
- 真正要解决的问题（基于真机模拟器截图 `image-8eb8c8e6` 实测诊断）：
  1. **五层 UI 上下夹击，把场景和雯宝挤在中间一条缝里**：
     - 顶部堆了 **3 层**（第 1 层：身份大胶囊 + 3 个圆形资源胶囊；第 2 层：小屋/庭院/街区 + 夜里 共 4 个胶囊；第 3 层：巨大的横幅心愿框挡在窗户正中央）。
     - 底部又堆了 **2 层**（第 4 层：巨大的四宫格白底卡片直接压在雯宝下半身和床/书桌上；第 5 层：底栏 4 个导航）。
     - 结果：5 层白底卡片占掉了近 45% 的屏幕面积，画面像后台控制面板，毫无呼吸感。
  2. **Android 模拟器字体缺少 Unicode 13+ Emoji 导致乱码豆腐块（`▯`）**：
     - 截图里零钱 `🪙`、摸摸头 `🤍` 在模拟器字体下全部显示成了刺眼的方框 `▯`（如 `▯ 53`、`▯ 摸摸头`）。

- 成熟竖屏养成游戏（《月兔奥德赛》《口袋营地》《旅行青蛙》）的标准布局法则：
  1. **顶栏极简「单行贴顶」**：左边一个紧凑身份胶囊（头像 + `Lv.X` + 细经验条），右边一个合并的「零钱 · 花种」双联胶囊；**绝不在顶部放第二排按钮、绝不在窗户正中间挂大横幅**。
  2. **中间 75% 屏幕完全留白给房间和角色**：
     - 雯宝的心愿不再做成挡窗户的巨型横幅，而是做成**贴在角色头顶/身侧的小巧对话气泡（Speech Pill）**，像她在轻声说话，点一下就能帮她完成。
     - 场景里的物件（床、书桌、花圃、喷泉）本来就可以直接点！不需要在画面中间再叠一层巨型四宫格卡片挡住雯宝的身体。
  3. **底部合并为「单层轻巧操控区」**：
     - 去掉挡在雯宝身上的巨型四宫格白框！
     - 改为贴底的 **「场景切换轻胶囊（小屋/庭院/街区）+ 2~3 个无底框的半透明轻巧互动圆钮」** + **极简底栏**，让雯宝从头到脚完整露出来。
  4. **全面替换不兼容 Emoji 为跨平台 100% 渲染的内联 SVG / 通用符号**：
     - 彻底干掉会变方框 `▯` 的 `🪙`、`🤍`、`🪴` 等高版本 Emoji，改用精致的内联 SVG 图标（金币圆章、爱心、花苗、图鉴书本），在任何 Android 模拟器与旧手机上都清晰美观、零豆腐块。

- 怎样算满足：
  1. **顶栏缩减为单行（高度 ≤ 54px）**：左身份（头像 + `Lv.4 午后茶友` + 经验细条），右资源胶囊（SVG 金币 + 花种），彻底拿掉顶部的第 2 排和第 3 排横幅。
  2. **雯宝全身与房间背景完整露出（中间 75% 无大块遮挡）**：移除压在雯宝身上的大号四宫格卡片 `.world-action-dock`。
  3. **心愿气泡与轻操作贴合在底部安全区上方（单行轻胶囊）**：
     - 底部导航栏上方只放一排轻巧胶囊：**左侧是场景切换（小屋 / 庭院 / 街区），右侧是当前心愿/互动轻按钮（如 `♥ 摸摸头`、`🍪 喂曲奇`、以及当前心愿一键达成）**，高度紧凑、不遮挡角色。
  4. **零 `▯` 乱码方框**：所有货币、爱心、动作图标改用内联 SVG 或 Android 全兼容图标。
  5. `npm run test:mobile` 与 `npm run build` 100% 通过。

- 现有能力：
  - `src/mobile/WorldApp.tsx`、`src/mobile/world.css`（已证实：只需重组 DOM 层级与 CSS 定位，底层 `codex.ts`、`runtime.ts` 逻辑无需改动）
  - 没有出处的词：无。

- 最小充分方案：
  1. 已拍板：按上述「单行极简顶栏 + 中间 75% 纯净房间舞台 + 底部单排轻胶囊（场景切换 & 轻互动）+ 内联 SVG 修复 `▯` 方框乱码」重构 UI 布局。

- 为什么更小的做法不够：
  - 只调小字号而不把顶部 3 层和底部 2 层合并，画面依然是 5 层横条夹着角色。
  - 不替换 `🪙` 和 `🤍`，在你的 Android 模拟器上依然是难看的方框 `▯`。

- 相关的债：
  - **A 现在偿还**：偿还高版本 Emoji 在 Android WebView 下的 `▯` 缺字债，以及 HUD 超出 15% 屏高预算的布局债。

- 这次不做：
  - 不删减任何 V3 玩法功能（图鉴、许愿扭蛋、自选种花、街角奇遇、面对面聊天全部保留，只是收束进干净的入口）。

- 风险：纯 UI 布局与 SVG 图标替换，零数据风险。
