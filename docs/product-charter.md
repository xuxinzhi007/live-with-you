## 一句话定义

《雯宝》是竖屏二次元**换装搭配闯关 + 心境羁绊卡收集 + AI 实时陪伴**手游。
玩家在试衣镜与舞台上为雯宝搭配服装与配件，闯关评级、收集套装与心境卡，并在密语里和她聊天。

## 北极星体验

打开数秒内看到雯宝与当前装扮；30 秒内完成一次换装或闯关反馈；
数日后衣橱解锁、升星与羁绊等级能看出自己玩过什么。

界面首先是试衣镜 / 舞台 / 图鉴，而不是任务清单。

| 体验支柱 | 玩家感受 | 系统表达 |
| --- | --- | --- |
| 我在打扮她 | 换装立刻反映在立绘上 | 五大槽位、纸偶叠加、骨骼工坊微调 |
| 搭配有目标 | 闯关有主题与评级 | 舞台章节、风格属性、技能与套装共鸣 |
| 收集有温度 | 单品与心境卡有故事 | 图鉴、升星、星愿幻阁 |
| 陪伴不断线 | 想聊就能聊 | Ollama 密语 + 离线回退；bond 亲密随互动增长（入口：底栏第 7 项） |
| 竖屏可单手 | 手机主线 | 顶栏资源 + 底栏导航，试衣镜优先 |

## 核心循环

进入大厅 / 试衣间 → 搭配五槽单品 →（可选）骨骼微调 → 主题闯关评级 →
礼券 / 解锁 / 升星 → 星愿幻阁抽取或工坊定制 → 密语陪伴 → 下次打开衣橱进度还在。

## 绝不做什么

1. 每日任务清单、签到催促、红点压迫。
2. 用体力或失败门槛锁死核心换装与闯关。
3. 常驻满屏数值仪表盘，遮挡立绘与试衣镜。
4. 把陪伴做成必须每日上线才能维持的惩罚系统。
5. 在未接入真实后端前，用本地通道假装完成实时多人。

说明：星愿幻阁的保底抽卡与工坊定制是**当前 V5 已实现的收集循环**，不属于上列禁止项。
V2 宪章中的「禁抽卡」仅适用于已归档的可走动小世界方案。

## 技术边界

- 入口唯一：`src/main.tsx` 挂载 `WorldApp`。无 `?legacy` / `?desktop` 双入口；无 `WorldView.tsx`；无 Pixi 运行时依赖。
- 渲染：React DOM + CSS。舞台立绘 = 角色皮肤帧或 Comfy 套装抠图 + SVG 可穿戴叠加 +（工坊内）骨骼切片预览。
- 衣橱数据：`src/mobile/world/nikki-wardrobe.ts`；骨骼：`skeleton-system.ts`；抠图与 SVG 叠加：`paper-doll-rig.ts`。
- 资源解析：`src/mobile/world/remote-assets.ts` + 环境变量 `VITE_ASSET_BASE_URL`。**默认不连资源库**：变量为空（当前默认）时只用仓库 `public/assets` 相对路径；显式配置且探活成功才走局域网 `/files/...`。当前**没有**图片加载失败时的自动 onerror 回退。
- 存档：衣橱本地键（如 `wenbebi-nikki-wardrobe-v8`）与世界 bond 存档键并存；新增字段须兼容旧档。
- Live2D / Spine 仅为未来可选方向，见调研文档；不得当作当前运行时。

## 版本路线（摘要）

- **现行 V5**：换装、闯关、幻阁、密语、骨骼工坊、远端资源库。
- **后续**：套装透明资产离线化、远端加载失败回退、真机回归；Live2D/Spine 仅在美术与许可就绪后评估。
- **历史 V2**：可走动房间 / 花圃 / 接球 — 代码岛与文档已归档或待清理，不再作为产品主线。

## 每次开发前的偏离检查

1. 玩家能在试衣镜或舞台上立刻看到变化吗？
2. 操作后是否有明确、可见的反馈（立绘 / 评级 / 文案）？
3. 是否留下衣橱、升星、羁绊或图鉴中的长期痕迹？
4. 它是低压力选择，还是伪装成奖励的每日任务？
5. 竖屏手机上是否不严重遮挡立绘，且单手可完成？
6. 去掉资源数字后，它是否仍然只属于雯宝与这份心境？
7. 旧存档、离线与局域网资源不可用时会怎样？

第 1、2、3 项中有两项为否，或第 4 项属于催促任务，则必须重设计或拒绝。
