**母图 + Qwen-Image-Edit-2509 Q4 图生图**，只改姿势/视角，锁定同一角色与白 T 白短裤，**不挂角色 LoRA**。

## 2. 成功标准

| 项 | 达标条件 |
| --- | --- |
| 身份 | 能对照母图认出同一人：短黑发、齐刘海、棕眼、轻微笑；比例正常，不是 Q 版大头 |
| 默认衣服 | 白短袖 T（有胸袋按画面实际左右）、白短裤、白鞋；白底干净 |
| 正式工作流 | 只跑 `Qwen_Image_Edit_2509_Q4_官方出图.json`，母图锁定，8GB 用已验证 Q4 组合 |
| 交付规格 | 760×760 RGBA、脚底约 y=748、水平中心 x≈380；入库后客户端不再二次洪水抠图 |
| 过审 | 每张过审图有对应 `wenbao` caption；拒收图不打标签、不入库 |
| 训练 | 未获同意保持关闭；将来开训只用过审集合、走 LoRA、不走 DreamBooth |

## 3. 出图契约（核心参数）

| 槽位 | 值 | 注意 |
| --- | --- | --- |
| 母图 | `Wenbao_redraw_00001_.png` | LoadImage；原生 512×768，不做放大缩放 |
| UNet | `Qwen-Image-Edit-2509-Q4_K_M.gguf` | UnetLoaderGGUF；官方 fp8 约 16GB，8GB 用 Q4 |
| CLIP | `qwen_2.5_vl_7b_fp8_scaled.safetensors`（type `qwen_image`） | 必须走 `CLIPLoader` |
| VAE | `qwen_image_vae.safetensors` | — |
| 加速 LoRA | Qwen Lightning 8steps，强度 1.0 | `LoraLoaderModelOnly`；**这是 Qwen 的加速 LoRA，不是角色 LoRA** |
| 采样位移 / CFGNorm | AuraFlow shift 3.0 / 1.0 | `ModelSamplingAuraFlow` |
| 采样 | seed 25091201、8 步、CFG 1.0、`euler` / `simple`、denoise 1.0 | — |
| 输出前缀 | `wenbao_qwen_edit_official/wenbao_q4_<变体>` | 换角度改前缀，避免覆盖 |

`/api/comfy/draw`（`vite.config.ts`）用的就是这套图：只覆盖正向/负向/seed/保存前缀，其余沿用。

## 6. 五步推进顺序

1. **判断是不是走错路**：旧 Q 版帧不是「再调一调就能用」，比例与服装都不是现行线。
2. **只留对新路线有用的**：新待机/呼吸/走路/头像不回退；过审 10 张留给其他槽位，不顶点击/坐/躺。
3. **补缺的槽位**：用母图编辑出图 → isnet-anime 去底 → 760 对齐 → 过目 → 换 `public/assets`。
4. **客户端只换图**：过审前不改槽位逻辑，不恢复四层，不指回 8788。
5. **停在该停的地方**：见下方暂停表。
