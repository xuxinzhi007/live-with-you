## 1. 产品是什么

《雯宝》是以角色雯宝为核心的竖屏换装搭配 + AI 陪伴产品，当前个人自用、无商业化计划。质量标准：特征正常、角色正确、画面干净、没有报错。

- 入口：`src/main.tsx` → `src/mobile/WorldApp.tsx`（React 19 + TypeScript + Vite，DOM/CSS，**没有 Pixi**）
- 北极星：打开数秒内看到雯宝和当前装扮
- 默认形象：白 T、白短裤、白鞋；短黑发、齐刘海、棕眼、浅笑。不锁 Q 版头身
- 本地预览：`npm run dev` → `http://127.0.0.1:5173/`（改 `.env` 要重启 Vite）

## 4. 资源与存档

- **默认只用本仓库 `public/assets`**：`getAssetBaseUrl()` 在 `VITE_ASSET_BASE_URL` 为空时返回 `""`（`remote-assets.ts:7`）。`.env` / `.env.example` 里 8788 已注释，`public/assets/manifest.json` 的 `baseUrl` 为空。
- 只有显式配置非空地址且探活成功，`resolveAsset` 才指向 `http://<host>/files/{dress|part|card|base|ui|world}/…`。
- 写入 8788 正式库仍**暂停**；局域网管理页未做鉴权，只适合内网。
- 仓库仍保留本地副本作回退；**尚未**把 `onError` 回退接到角色 `<img>` 上。
- 三张 Comfy 主装扮仍是不透明 512×640，运行时对 `dress-*` 走洪水填充抠图。离线透明 760 规格资产是后续项。
