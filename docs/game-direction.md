## 产品定位

《雯宝》是竖屏换装搭配手游：玩家为雯宝搭配主装扮、头饰、手持、光环与心境卡，
在主题舞台上闯关评级，在星愿幻阁收集单品，并在密语里与她聊天。

它不是任务列表，也不是操作密集型动作游戏；每次换装与闯关都要有看得见的立绘或评级反馈。

## 平台策略

- **竖屏移动端是唯一主线**。
- 入口：`src/main.tsx` → `WorldApp`。无桌面 `?desktop` / 旧移动 `?legacy` 双轨。
- 常驻：顶栏身份/礼券/亲密 + 底栏七项（大厅 / 小世界 / 衣橱 / 闯关 / 幻阁 / 图鉴 / 密语）。
- 渲染：React DOM；不依赖 Pixi。

## 核心循环

1. 封面进入大厅，看到当前全身装扮。
2. 衣橱五槽搭配；可选骨骼工坊微调关节与配件锚点。
3. 主题闯关：按风格属性与技能评分，得到 `C`–`SSS` 评级与礼券。
4. 星愿幻阁单抽 / 五连；或工坊定制未解锁单品；重复件升星。
5. 密语聊天（局域网 Ollama，失败则离线回退）；亲密随互动增长。
6. 下次打开，衣橱与羁绊进度仍在。

## 资源

- 远端资源库：`VITE_ASSET_BASE_URL`。**默认留空 = 只用仓库 `public/assets`**；显式配置且探活成功时，由 `src/mobile/world/remote-assets.ts` 把公共路径映射到 `/files/{dress|part|card|base|ui|world}/…`。
- 环境变量为空时使用仓库内 `public/assets` 路径。本地副本暂作回退，尚未做图片 onerror 自动切换。

## 上线验收（现行）

- 换装后试衣镜立绘与配件叠加正确。
- 闯关评级、幻阁抽取、升星与本地衣橱存档可完成并刷新保留。
- 密语在局域网可达时连上模型，不可达时离线回复（底栏第 7 项进入）。
- `npx tsc --noEmit` 与 `npm run test:mobile` 通过。
