# 雯宝游戏方向（摘要 · V2）

> 完整且具有约束力的规格见 [产品宪章 V2](./product-charter.md)。两者冲突时，以产品宪章为准。
> 旧的“观察雯宝生活”摘要已废止。

## 产品定位

《雯宝》是一款竖屏、单手、低压力的小世界生活游戏。玩家扮演雯宝本人，在一个横向比屏幕宽、
可以走动的房间里生活：用家具、照料花圃、去街区买东西、踢球，做一些五分钟就能完成的小事。
它不是任务列表，也不是操作密集型动作游戏；每个交互都要有看得见的角色或物件反馈。

## 平台策略

- **竖屏移动端是唯一主线**：目标 360–430px 宽、单手拇指。
- 常驻界面只有顶部身份/资源和底部 3 项；其余收进半高抽屉。
- 场景内只保留一个情境按钮和一条短提示，不用常驻地点条。
- 桌面版 `?desktop` 与旧移动端 `?legacy` 只作为预览/回滚，不再接新玩法。

## 核心循环

1. 进入房间，看到角色和当前可做的事。
2. 点地面走过去；点物件走近后出现一个情境按钮。
3. 执行动作：休息、阅读、看收藏架、种花/浇水/收花、买种、许愿、踢球。
4. 获得即时反馈：动作、姿态、气泡、物件状态、数值变化。
5. 留下长期痕迹：花束、花种、纪念、收藏、最高连击、生活小记。
6. 下次打开，房间和收藏还在，且能继续玩。

## 移动端玩法基线

1. **看见**：打开 5 秒内看到角色、房间和至少一个可做之事。
2. **行动**：所有操作在场景里完成；门是唯一的跨房间入口。
3. **反馈**：动作/位移 → 文案 → 物件状态 → 少量特效 → 数值，顺序不能倒。
4. **积累**：种花闭环（买种 → 种 → 浇 → 收 → 留种）和接球连击形成可见长期变化。
5. **返回**：单次 30 秒–3 分钟；随时可以停，没有失败、体力墙或签到。

常驻内容 HUD（顶部身份 + 底栏）不超过屏高 15%，不含系统安全区；抽屉不超过 40dvh。

## 交互原则

- 一次点击只做一件事：物件 > 角色 > 地面。
- 装饰物（地毯、绿植）不是点击目标，也不能有横穿可行走带的碰撞盒。
- 短冷却只作用于同一物件，必须显示剩余秒数，且不能阻止玩家去别处玩。
- 球飞出后点球即可接住；接不到只重置连击，不惩罚。
- 镜头默认跟随；手动拖镜头后暂停，再次移动或交互时温和恢复。
- 尊重 `prefers-reduced-motion`：关闭走路帧、镜头缓动和循环动画，保留状态变化。

## 房间与出口

当前三个房间，全部通过场景内的门往返：

- **小屋**：床（休息）、书桌（阅读）、收藏架、两扇门（庭院 / 街区）。
- **庭院**：三块花圃（种/浇/收）、小皮球（踢/接）、回屋的门。
- **街区**：喷泉（许愿）、花摊（买种）、长椅（坐）、回家的门。

不加地点标签页，不做瞬移。新增房间必须包含：独有背景、2 个可交互物件、
1 条不被装饰物截断的可行走带、1 扇清晰的门。

## 上线验收

- 390 × 844 下：角色、房间、情境按钮都可见，常驻 HUD 不遮角色脸。
- 点地面能走、点物件能走近并触发、点门能换房间。
- 种花闭环和接球闭环都能完成，刷新后状态保留。
- 所有触控目标 ≥ 44px；单手可完成核心操作。
- 构建产物可直接部署到 Netlify；旧存档能正常迁移。
