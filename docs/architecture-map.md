## 二、核心数据模型

```
GameState (一份存档走天下)
├── coins        礼券（闯关/抽卡/升星的经济货币）
├── seeds        花种（小世界种植用）
├── flowers      花束（收获产出，可卖）
├── bond         亲密值（驱动等级 + 解锁内容）
├── mementos     纪念物数量
├── journal[]    生活小记（文本日志）
├── bondedMoments[]  已触发的羁绊时刻
├── pet          精力/心情/当前动作
└── world
    ├── room         当前房间 (home/garden/street)
    ├── skin         角色皮肤 (original/maid)
    ├── plots[3]     花圃（种类/种下时间/浇水时间）
    ├── cooldowns    物件冷却表
    └── collection   花朵收集 (daisy/rose/sunflower)
```

### 经济闭环

```
        ┌─────────────────────────────────────┐
        │              礼券 (coupons)           │
        │  唯一硬通货，驱动换装/抽卡/升星        │
        └──────┬───────────────┬────────────────┘
               │               │

        │  搭配闯关赢  │  │ 抚摸雯宝    │

               │

        │  · 定制未解锁单品 (10/16/28)       │

        │  · 星愿幻阁抽卡 (单抽/五连)         │
        └───────────────────────────────────┘
```

### 亲密系统（bond）

```
  互动行为              亲密值
  ─────────────────────────────
  抚摸雯宝              +少量 (60s冷却)
  送花/送点心           +中量
  抽卡获得新品          SSR+18 / SR+10 / R+6
  闯关胜利              +大量
  小世界物件交互         +少量~中量
  种植收获              +少量
        │
        ▼
  ┌─────────────┐
  │  等级提升    │──→ 解锁新闯关章节 / 新对话 / 新内容
  │  Lv.1 → N   │
  └─────────────┘
```

### 小世界种植闭环

```
  买种(6零钱2颗) → 种下 → 浇水(成长减半) → 开花 → 收花
       │                                    │
       └──── 60s ──── 30s ──── 立即 ◄───────┘
                                          │
                                    ┌─────▼─────┐
                                    │ +1花束    │
                                    │ +1花种    │
                                    │ 首次进收藏 │
                                    └───────────┘
```

## 五、一句话总结

> **单组件 WorldApp 通过 `screen` 状态切换 9 个屏幕，所有玩法数据汇入一份 `GameState` 存档，换装/抽卡/闯关是纯函数驱动，小世界和 AI 陪伴是独立模块，经济闭环围绕「礼券」一个硬通货。**
