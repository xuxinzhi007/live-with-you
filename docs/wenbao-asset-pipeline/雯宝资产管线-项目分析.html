二、设计说明

1. 身份怎么锁

正式身份不靠「再训一个马上挂上的 LoRA」，而靠一张已经验收的母图，用指令式图像编辑改视角和姿势、保持同一人。这是图像编辑模型的典型用法：把「是谁」放在输入图里，提示词只描述「改什么」，并声明其余保持不变。旧的「文生图 + 角色 LoRA + IPAdapter + OpenPose」已归档，不是现行正式出图。

  • 身份与默认衣服标准：Wenbao_redraw_00001_.png。短黑发、齐刘海、大圆棕眼、轻轻笑着；白短袖 T 恤（母图胸袋在角色右侧胸部，画面左侧）、白短裤、白鞋；正面站立、全身、脚可见、纯白底。
  • 比例：正常动漫比例。待机图只作五官参考，不锁成 Q 版大头。正式提示词和新 caption 都不写 chibi / Q 版 / 大头。
  • 质量条：特征正常、角色正确、画面干净。用户已确认当前官方出图可通过。
不能把旧 LoRA 挂到 Qwen。wenbao_v1.safetensors 和 xiaoyan.safetensors 是给 SD 1.5（MeinaMix）用的，作用在 SD UNet 和 CLIP 上。Qwen-Image-Edit-2509 是另一套骨架（Qwen2.5-VL + 自己的 DiT，VAE 是 qwen_image_vae），权重对不上。群内已约定：客户端对齐时走「母图 + 提示词」，不挂 wenbao_v1。磁盘上的 LoRA 保留，只属于已归档的 MeinaMix 路径（须显式 --legacy-meinamix）。

提示词原则：只改镜头或姿势，明确同一人、同一张脸、同一套衣服、白底、全身、脚可见；写出白 T / 白短裤 / 白鞋和要保持的五官；明确自然动漫比例、不要 Q 版；换角度时写清左右与俯仰，不要混用。实验文件 Qwen_Image_Edit_2509_Q4_experimental.json 保留，不是正式出图默认。

3. Caption 规则

给将来的 LoRA 用，不是给 Qwen 官方出图用（官方出图吃自然语言提示词）。

  1. 触发词 wenbao 打头，然后 1girl, solo。
  2. 齐刘海、大圆棕眼、轻轻笑着等身份特征锁在触发词里，不要写进每张 caption。
  3. caption 只写该图会变的部分：衣服、姿势、构图、视角、画面上实际出现的口袋 / ahoge 等。
  4. 过审衍生集里只要画面就是默认套装，就写 white t-shirt, white shorts, white shoes。
  5. 口袋、手的位置按画面实际标，不要想当然写成「标准双手背后」或母图的左右。
  6. 远鞋略灰仍写 white shoes，不要写成灰鞋。
  7. 新过审图不写 chibi / Q 版 / 大头。旧 6 张同伴图里画面本身是 Q 版的仍保留 chibi，这轮不改。
  8. 只把 caption 写在过审目录；未同意前不写入 10_xiaoyan。拒收目录不打标签。
