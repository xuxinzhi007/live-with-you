## 1. 身份怎么锁

正式身份不靠「再训一个马上挂上的 LoRA」，而靠一张已经验收的母图，用指令式图像编辑改视角和姿势、保持同一人。

- **身份与默认衣服标准**：`Wenbao_redraw_00001_.png`
  - 短黑发、齐刘海、大圆棕眼、轻轻笑着
  - 白短袖 T 恤（母图胸袋在角色右侧胸部，画面左侧）、白短裤、白鞋
  - 正面站立、全身、脚可见、纯白底
- **比例**：正常动漫比例。待机图 `待机状态.png` / `standby-bust-white.png` 只作五官参考，不锁成 Q 版大头模板。不要在正式提示词或新 caption 里写 `chibi` / Q 版 / 大头。
- **质量条**：特征正常、角色正确、画面干净、没有明显错误。用户已确认当前官方出图可通过。

这是图像编辑模型的典型用法：把「是谁」放在输入图里，提示词只描述「改什么」（视角、姿势），并反复声明「其余保持不变」。它与旧的「文生图 + 角色 LoRA + IPAdapter + OpenPose」是两条不同的锁身份路径。旧路径已归档，不是现行正式出图。

## 2. 为什么不能把旧 LoRA 挂到 Qwen

`wenbao_v1.safetensors` 和 `xiaoyan.safetensors` 是给 SD 1.5（MeinaMix）用的 LoRA：作用在 SD UNet 和 CLIP 文本编码器上。Qwen-Image-Edit-2509 是另一套骨架（Qwen2.5-VL 文本侧 + 自己的 DiT / UNet，VAE 也是 `qwen_image_vae`）。权重形状和接口都对不上，硬挂既不是官方线，也没有技术根据。

群内已约定：对齐客户端时走「母图 + 提示词」，不挂 `wenbao_v1`。磁盘上的 LoRA 保留，需要时只属于已归档的 MeinaMix 路径（须显式 `--legacy-meinamix`），不是正式出图。

## 4. Caption 规则

给将来的 LoRA 用，不是给 Qwen 官方出图用（Qwen 官方出图吃的是上面的自然语言提示词）。规则要长期一致：

1. 触发词 `wenbao` 打头，然后 `1girl, solo`。
2. 齐刘海、大圆棕眼、轻轻笑着等身份特征锁在触发词里，**不要**写进每张 caption。
3. caption 只写该图会变的部分：衣服、姿势、构图、视角、画面上实际出现的口袋 / ahoge 等。
4. 默认衣服在过审衍生集里，只要画面就是这套，就写 `white t-shirt, white shorts, white shoes`。
5. 口袋、手的位置按画面实际标，不要想当然写成「标准双手背后」或母图的左右。
6. 远鞋略灰仍写 `white shoes`，不要写成灰鞋。
7. 新过审图不写 `chibi` / Q 版 / 大头。旧的 6 张同伴图里，画面本身是 Q 版的仍保留 `chibi`，不在这轮改。
8. 只把 caption 写在过审目录；未同意前不写入 `10_xiaoyan`。拒收目录不打标签。

这与角色 LoRA 的常见纪律一致：触发词承担身份，caption 承担变化，避免每张都重复五官导致过拟合、或把缺陷标进模型。
